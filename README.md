# Pitaka — expense tracker

A personal money tracker that runs entirely in the browser. No account is needed; everything saves automatically on the device.

## Features

- **Money in, out and savings**, each with an account: cash, credit card, bank or e-wallet
- **Day, week, month and year summaries** with a chart you can tap to drill into
- **Monthly and weekly budgets**, plus a per-category budget plan and the 50/30/20 rule
- **Need or want** on every expense
- **Bills** with due dates, marked paid, due soon or overdue
- **Savings goals** and a **monthly wishlist** linked to goals and categories
- **Books** to keep separate records (personal, business, family)
- **Calculator**, and math right in the amount field (`120+45*2`)
- **Excel export and import** (.xlsx, .xls, .csv)
- **Optional sign-in** so people sharing a device each get a private space

Data is stored in the browser's local storage, so it stays on that device and browser.

## Run it

```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, Tailwind CSS, Motion and Lucide icons.
